# Contributing

Thank you for your interest in this project.

## Report an Issue

If you encounter a problem, please open an issue instead of modifying the source code directly.

A good issue report should include:
- A clear title
- The steps to reproduce the problem
- The command you used
- What you expected to happen
- What actually happened
- Your environment details (OS, Go version, etc.)

## Source Code

This repository is managed as a read-only source for general users.

- Users may use the project freely
- Users may report bugs and request features via GitHub Issues
- Users should not modify the source code in this repository directly unless they have explicit write access

## Forks and Pull Requests

If you want to contribute code:
1. Fork the repository
2. Create a new branch
3. Make your changes
4. Submit a pull request

Maintainers will review pull requests before merging.
